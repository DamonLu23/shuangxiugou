## 数据质量设计（已实现）

1. **证据只存结论**：来源链接 + 命中关键词 + 日期 + 打分 + 标题 + 摘要片段，不存正文
2. **公司名归一化**：`normalize.py` 剥离 分公司/子公司/括号城市，需前缀+机构词匹配防错挂（新疆华为商贸 ≠ 华为）
3. **劳务中介过滤**：岗位卡片公司名不匹配种子 key → 丢弃（智联大量普工/外包岗位）
4. **Bing 噪音域名黑名单**：百科/知道/微信文章/新闻聚合（无员工语境却含 双休/996 字样）
5. **打分词表**：`scoring/keywords.py` —— 正信号（周末双休 +2 等）、负信号（996 -3、做六休一 -2 等），加班 -0.5 作为弱文化信号
6. **等级聚合**：`backend/app/services/levels.py` —— 来源权重（合同>offer>口碑>岗位>官方）× 时间衰减，加权平均 → L1~L6 + 置信度

## 覆盖率预期（20 家抽样 45%）

- 有证据：45% 左右（互联网/快消/家电 招聘与口碑讨论多）
- 无证据（= 待验证 L6）：如 小米/OPPO/vivo/格力 等依赖 BOSS 的招聘主渠道公司
- 后续增量源候选：猎聘（完整内核）、BOSS（账号方案）、UGC 上报

### 调参记录（3 轮，含失真案例复盘）

| 问题 | 根因 | 修复 |
|---|---|---|
| 字节跳动被评 L1 1.0 失真 | 招聘帖/软文「双休」宣传词权重过高 | job_post 权重 0.5→0.4；「双休」词分 1.5→0.8；宣传软文单独分类权重 0.1 |
| 百度百科「996」噪音 | 百科公司词条含无关 996 字样 | 百科/知道/新闻聚合域名进黑名单 |
| 知乎「XX公司双休吗」误打 | 问句标题本身含关键词 | 问句标题仅按正文片段打分 |
